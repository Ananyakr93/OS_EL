# EncFS Dashboard Guide

This guide provides step-by-step instructions for installing, running, and using the web-based dashboard for the Secure FUSE File System.

## 1. Prerequisites

Ensure you have the following installed on your Linux system:

*   **Python 3**: `sudo apt install python3`
*   **Pip**: `sudo apt install python3-pip`
*   **FUSE 3**: `sudo apt install libfuse3-dev`
*   **Build Tools**: `sudo apt install build-essential pkg-config`

Install the Python dependencies:

```bash
cd dashboard
pip3 install -r requirements.txt
# OR manually:
pip3 install flask matplotlib numpy
```

## 2. Terminology

*   **Cipher Directory**: The directory where encrypted data is actually stored on your disk.
*   **Mount Point**: The empty directory where you will see and interact with your decrypted files.

The dashboard automatically manages these standard directories inside the project root:
*   `cipher/` (storage)
*   `mnt/` (access)

## 3. Starting the Dashboard

1.  Navigate to the project root:
    ```bash
    cd /path/to/OS_EL
    ```

2.  Run the dashboard application:
    ```bash
    cd dashboard
    python3 app.py
    ```

3.  Open your web browser and go to:
    **[http://localhost:5000](http://localhost:5000)**

## 4. Using the Dashboard

### A. Home Screen (System Overview)
*   **Status Indicators**: Shows whether the filesystem is currently "Mounted" or "Unmounted".
*   **Mount Action**:
    1.  Click **Mount Filesystem**.
    2.  Enter a **Passphrase** (remember this!).
    3.  Select a **Mode**:
        *   **Secure**: AES-256-GCM (Best security).
        *   **Speed**: AES-256-CTR (Faster for large files).
    4.  Click **Mount**.
*   **Unmount Action**:
    *   Click **Unmount** to safely stop access.
    *   Use **Force (Lazy)** if the filesystem is busy/stuck.

### B. File Explorer
Once mounted, go to the **Explorer** tab to manage files.

*   **Upload**: Click "Upload File" to securely store a file. It will be encrypted automatically on the backend.
*   **Download/View**: (Note: Direct download from browser not implemented in demo, but files are accessible in `OS_EL/mnt/` on your machine).
*   **Delete**: Click the trash icon to remove a file.
*   **Set Policy**:
    1.  Click the **Gear Icon** next to a file.
    2.  Choose a policy (e.g., "HEAD:100" to only encrypt the first 100 blocks).
    3.  Click **Apply**.
*   **Verify Proof**:
    1.  Click the **Shield Icon**.
    2.  This generates a Zero-Knowledge Proof simulation verifying the file's integrity without revealing the key.

### C. Benchmarks
Go to the **Benchmarks** tab to analyze performance.

1.  Click **Run Benchmarks** (this may take a minute).
2.  Click **Generate Graphs** to visualize the results.
3.  View charts for:
    *   Throughput (Secure vs Speed vs Raw).
    *   Latency.
    *   CPU Overhead.

### D. Logs
The **Logs** tab shows the real-time performance logs generated by the `encfs` daemon, useful for debugging or performance analysis.

## 5. Troubleshooting

*   **"Permission Denied"**: Usually caused by a stale mount. Run `fusermount3 -u mnt` in the terminal to clean it up.
*   **Mount fails silently**: Check if the `cipher` or `mnt` directories exist and are writable.
*   **Port 5000 busy**: Edit `app.py` to change the port number at the bottom of the file.
