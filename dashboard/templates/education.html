Welcome to NovaFS

A High-Performance, Secure FUSE File System with Zero-Knowledge Auditing

Project Overview

NovaFS is a secure encrypted file system implemented in userspace using FUSE (Filesystem in Userspace). It is designed to provide transparent encryption, ensuring that your data remains secure on disk while being seamlessly accessible to authorized applications.

Unlike traditional encrypted file systems, NovaFS introduces novel features like Hybrid Block Compilation for performance and Zero-Knowledge Proofs for privacy-preserving auditing, making it suitable for modern, security-conscious environments.

Architecture
  • User App: Writes data to mount point.
  • FUSE Kernel: Forwards request to NovaFS daemon.
  • NovaFS Daemon: Encrypts data (AES-256) & Key Management.
  • Disk Storage: Saves encrypted blobs to Cipher Dir.

Why NovaFS Matters to You

Simple, powerful protection for your digital life—no tech degree required.

Safe Cloud Storage

Upload your photos and docs to Google Drive, Dropbox, or iCloud without worry. NovaFS locks them before they leave your computer, so big tech companies can never peek at your private data.

Theft Protection

If your laptop is lost or stolen, your data remains invisible. Without your passphrase, your financial records, family memories, and passwords look like meaningless random noise to a thief.

Invisible Security

You don't need to change how you work. Just save files to your "mnt" folder like normal. NovaFS handles all the complex encryption math automatically in the background.

Key Features

Strong Security

Uses AES-256-GCM for authenticated encryption. Each 4KB block has a unique, random IV to prevent watermark attacks. Passphrases are hardened using PBKDF2 (10,000 rounds).

High Performance

Features Hybrid Block Compilation ("Superblocks"). It detects sequential I/O and batches 32KB chunks, reducing system call overhead by up to 8x compared to standard FUSE loops.

Adaptive Policies

Supports fine-grained policies via Extended Attributes (xattr). You can set files to Speed Mode (AES-CTR) or partial encryption (e.g., HEAD:100) to encrypt only file headers.

Privacy-Preserving Auditing

What is Zero-Knowledge Proof (ZKP)?

A Zero-Knowledge Proof allows one party (the prover) to prove to another party (the verifier) that a statement is true, without revealing any information beyond the validity of the statement itself.

In NovaFS, we use ZKPs to prove that you possess the correct decryption key for a file without ever revealing the key itself to the auditor or the server.

How it Works
  1. Setup: The file is encrypted with a master key.
  2. Challenge: An auditor requests proof of ownership.
  3. Proof Generation: NovaFS generates a cryptographic proof using the file's metadata and the user's key.
  4. Verification: The auditor verifies the proof against the public metadata. If it matches, they know the user has the key.
Benefits
  • No Key Leakage: Your password never leaves your device.
  • Compliance: Meets strict data privacy regulations (GDPR, HIPAA).
  • Trustless: You don't need to trust the auditor with your secrets.
