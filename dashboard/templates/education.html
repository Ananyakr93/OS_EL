Privacy-Preserving Auditing

What is Zero-Knowledge Proof (ZKP)?

A Zero-Knowledge Proof allows one party (the prover) to prove to another party (the verifier) that a statement is true, without revealing any information beyond the validity of the statement itself.

In NovaFS, we use ZKPs to prove that you possess the correct decryption key for a file without ever revealing the key itself to the auditor or the server.

How it Works
  1. Setup: The file is encrypted with a master key.
  2. Challenge: An auditor requests proof of ownership.
  3. Proof Generation: NovaFS generates a cryptographic proof using the file's metadata and the user's key.
  4. Verification: The auditor verifies the proof against the public metadata. If it matches, they know the user has the key.
Benefits
  • No Key Leakage: Your password never leaves your device.
  • Compliance: Meets strict data privacy regulations (GDPR, HIPAA).
  • Trustless: You don't need to trust the auditor with your secrets.
