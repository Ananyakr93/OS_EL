Key Concepts

  • PBKDF2: Derives master key from passphrase (10,000 iterations).
  • Per-Block IV: Each 4KB block has a unique random IV preventing pattern attacks.
  • HMAC-SHA256: Metadata file integrity is verified before parsing.
  • Superblocks: 32KB batched I/O reduces syscall overhead by 8x.
  • ZK-SNARKs: Prove decryption capability without revealing secrets.
